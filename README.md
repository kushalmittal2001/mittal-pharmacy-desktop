# Mittal Pharmacy Admin — desktop app

Downloads only. The app's source code lives in a private repository.

The desktop app opens the prepaid-orders dashboard. It rings and speaks new orders even when it's minimized, shows pop-ups, prints packing slips silently when an order is accepted, starts with the computer and keeps it awake.

## Installing

**Windows:** run the file. If you see "Windows protected your PC", click **More info**, then **Run anyway**. The app installs, opens, and adds a desktop shortcut.

**Mac:** open the .dmg and drag the app into **Applications**. If macOS says it can't verify the app, open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**.

On first launch, allow notifications so order pop-ups can appear.
